# Генератор счетов (Invoice Generator)

**Индивидуальный проект** — паттерн проектирования **Prototype** (Прототип).

**Автор:** Дорошкевич Матвей Евгеньевич ПИ-251

---
Постановка задачи

Необходимо разработать генератор счетов, который позволяет:

- создавать и хранить шаблоны счетов (реквизиты продавца, валюта, ставка НДС, типовые позиции);
- быстро выставлять новые счета разным клиентам на основе шаблона;
- клонировать шаблон, изменять его (НДС, позиции) и не затрагивать оригинал в реестре.

Реализация: консольное приложение на **C# (.NET Framework 4.7.2)**.

---

Реальный сценарий применения

Индивидуальный предприниматель или небольшая компания в Кемерово регулярно выставляет счета за одни и те же услуги (консультации, разработка, поддержка). Каждый раз вручную заполнять реквизиты и строки неудобно.

**Решение:**

1. Один раз создаётся шаблон «Стандартные услуги» (продавец, НДС 20%, типовые позиции, валюта **RUB**).
2. Для нового клиента (например, **Doroshkevich ME**) шаблон **клонируется**, подставляются имя и адрес клиента — готовый счёт.
3. Для клиента без НДС используется отдельный шаблон `no-vat`.
4. Счёт сохраняется в текстовый файл в папку `output/`.

Так сокращается время на рутинные операции и снижается риск ошибок при копировании данных.

---

Паттерн Prototype (Прототип)

Зачем нужен

Создание сложного объекта «с нуля» (шаблон счёта с продавцом и списком позиций) затратно по времени и коду. Чаще нужна **копия** с небольшими изменениями (другой клиент, другая ставка НДС, дополнительная услуга).

**Prototype** позволяет клонировать существующий объект вместо повторной сборки.

### Какую проблему решает в проекте

| Проблема | Решение через Prototype |
|----------|-------------------------|
| Повторное заполнение одних и тех же полей | Клон шаблона копирует продавца, валюту, НДС, позиции |
| Изменение клона портит оригинал в реестре | `Clone()` создаёт **независимую** копию (глубокое копирование) |
| Разные варианты счетов (с НДС / без) | Несколько прототипов в `TemplateRegistry` |

Ключевые элементы

- `IPrototype` — интерфейс с методом `Clone()`.
- `InvoiceTemplate` — конкретный прототип (шаблон счёта).
- `TemplateRegistry` — хранит оригиналы шаблонов по ключу.
- `InvoiceGenerator` — при создании счёта вызывает `GetClone()`, затем `CreateInvoice()`.

При создании счёта продавец и позиции также копируются.

Использование

После запуска отображается меню:

```
=== INVOICE GENERATOR ===
1. List templates
2. Create invoice from template
3. Clone template and create invoice
4. Run demo scenarios
0. Exit
```

### Пункт 1 — список шаблонов

Показывает ключи в реестре: `no-vat`, `standard`.

### Пункт 2 — счёт из шаблона

1. Ввести ключ шаблона (`standard` или `no-vat`).
2. Ввести номер счёта, дату (`dd.MM.yyyy`), имя и адрес клиента.
3. Счёт выводится в консоль и сохраняется в `output/<номер>.txt`.

### Пункт 3 — клон шаблона (Prototype)

1. Выбрать шаблон.
2. При необходимости изменить ставку НДС.
3. При необходимости добавить позицию.
4. Ввести данные счёта и клиента.

Демонстрирует клонирование без изменения оригинала в реестре.

### Пункт 4 — демо-сценарии

Автоматически выполняются 5 сценариев (удобно для видео-отчёта и защиты):

| Сценарий | Описание |
|----------|----------|
| 1 | Список шаблонов в реестре |
| 2 | Счёт `INV-001` из `standard` (НДС 20%), клиент Doroshkevich ME |
| 3 | Счёт `INV-002` из `no-vat` (НДС 0%) |
| 4 | Клон `standard`, НДС 10%, счёт `INV-003` |
| 5 | Клон `standard` + новая позиция, счёт `INV-004` |

Файлы сохраняются в `Individual_project/bin/Debug/output/`.

История разработки (GitHub Flow)

Разработка велась по этапам в отдельных ветках с коммитами:

1. Сборка каркаса (`Invoice`, `InvoiceItem`, `SellerInfo`)
2. Шаблон счёта (`InvoiceTemplate`)
3. Паттерн Prototype (`IPrototype`, `Clone`)
4. Реестр и генератор (`TemplateRegistry`, `InvoiceGenerator`)
5. Демо-сценарии и экспорт в файл
6. Рефакторинг, меню, ввод пользователя
